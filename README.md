# IT-SPK

Лендинг для IT-аутсорсинговой компании в Киеве — портфолио-работа 2022 года.

**Demo:** [wyndace.github.io/itspk](https://wyndace.github.io/itspk/)
**Figma:** [макет](https://www.figma.com/file/V4g9FFeYTZLFxw6ClBF8iK/%5BPublished%5D%5BRU%5D-IT-SPK)

## Структура сайта

- Hero — оффер с формой заявки
- Услуги и цены
- О компании / организация
- Клиенты
- Форма связи + модальное окно

## Стек

- Gulp + SCSS
- Шрифт Montserrat
- Vanilla JS (модалки, формы)
